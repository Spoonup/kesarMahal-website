# Kesar Mahal storefront

React + Vite + React Router. Cart, sign-in and orders persist in `localStorage` (no backend yet).

    npm install
    npm run dev      # http://localhost:5173
    npm run build

Stubs to replace: payment (`src/pages/Checkout.jsx`), OTP/Spoonup auth (`src/pages/SignIn.jsx`), lot lookup + catalogue (`src/data.js`).
